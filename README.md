# Skills para Contadores — 57 agentes operacionais

Skills prontas para uso no Claude Code voltadas para contadores brasileiros. Cada skill é um agente especializado que executa uma rotina real do escritório contábil — apurações, obrigações acessórias, fechamento, recuperação de créditos, IRPF, atendimento fiscal — com passo a passo, fórmulas, templates e checklist de validação.

## Como usar

1. Copie a pasta `skills/` (ou pastas individuais) para o seu projeto Claude Code, dentro de `.claude/skills/`.
2. Em cada conversa, invoque a skill com `/nome-da-skill` ou peça em linguagem natural — o Claude Code vai carregar a skill correspondente.
3. Forneça os inputs pedidos (planilhas, XMLs, balancetes, contratos sociais).
4. Valide a saída com o checklist final da skill antes de protocolar/transmitir.

## Avisos legais

- As skills refletem a legislação vigente em 2026 e fazem referência a normas específicas (LC 123/2006, IN RFB nº 2.005/2021, CPC, CLT, etc.). Sempre confira a versão mais recente das normas e leiautes.
- Outputs gerados pelas skills são **rascunhos operacionais**; o contador responsável deve revisar e assumir a responsabilidade técnica (CFC).
- Templates e exemplos usam dados fictícios.
